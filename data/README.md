# 数据录入格式

把 500 C 与 600 C 的实验表整理成一个 CSV 或 XLSX 表。推荐使用长表格式：

- 每一行 = 一个化合物在一个测试温度下的一条实验记录。
- `temperature_c` 填 500 或 600。
- `rho` 填对应温度下的电阻率，单位保持一致，例如全部使用 ohm cm。
- 其余列使用图三中的特征符号，列名必须与模板一致。

可直接复制 `resistivity_measurements_template.csv` 的表头。

## 关键建议

1. 电阻率通常跨越多个数量级，训练脚本会默认学习 `log10(rho)`，因此 `rho` 必须为正数。
2. 如果同一配方有多次重复实验，建议保留重复行；模型会学习工艺与实验波动。
3. 如果某个特征暂时缺失，单元格可留空，训练时会用中位数填补；但列名本身必须存在。
4. 如果想分别建立 500 C 与 600 C 模型，训练时使用 `--temperature 500` 或 `--temperature 600`。
5. 如果想建立一个跨温度模型，训练时加入 `--include-temperature`，并确保候选表也包含 `temperature_c`。
